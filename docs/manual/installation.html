RadMon Installation Guide

Production Windows dipasang melalui RadMon-Setup.exe. Installer menempatkan app\RadMon.exe, membuat config\.env bila belum ada, mendaftarkan Scheduled Task RadMon Server, dan membuka port 8090/3300 hanya untuk LocalSubnet.

Layout persistent

RadMon\
  app\
    RadMon.exe
    web\
    docs\manual\
    grafana\
  config\
    .env.example
    .env
  runtime\
  archives\
  reports\

First installation pada central PC 192.168.1.2

  1. Jalankan RadMon-Setup.exe sebagai Administrator.
  2. Edit config\.env dan isi central/source database credential.
  3. Untuk security DB baru, isi RADMON_BOOTSTRAP_ADMIN_USER, password, dan PIN satu kali.
  4. Pastikan Grafana native tersedia di port 3300; isi RADMON_GRAFANA_BIN bila lokasinya non-standar.
  5. Restart Scheduled Task RadMon Server atau reboot setelah konfigurasi lengkap.

URL

http://192.168.1.2:8090/       Grafana monitoring kiosk tanpa login RadMon
http://192.168.1.2:8090/app    RadMon Control Plane, wajib login
http://localhost:3300          Grafana admin/editor pada PC server

Viewer, Operator, dan Administrator semuanya wajib login RadMon. Anonymous hanya melihat Grafana read-only dari network BRIN/LAN yang diizinkan.

Grafana persistent

Production normal memakai Grafana native, bukan Docker Desktop. Factory dashboard hanya di-seed jika resource belum ada. Dashboard yang sudah tersimpan tidak di-overwrite pada startup. Administrator dapat Edit dan Save dari localhost:3300; hasil Save langsung dipakai monitoring dan tetap ada setelah restart atau upgrade.

24/7 Windows lifecycle

Scheduled Task menjalankan app\RadMon.exe --server sebagai SYSTEM saat startup Windows dan mencoba restart otomatis bila proses berhenti. Menutup browser tidak mematikan server.

Upgrade

Jalankan installer baru sebagai Administrator. Installer mengganti aplikasi tetapi mempertahankan config\.env, runtime\, archives\, dan reports\.

Source production

gd50 -> 192.168.1.50:3306 / ipradmon
gd52 -> 192.168.1.52:3306 / ipradmon
gd38 -> 192.168.1.38:3306 / ipradmon

RadMon tidak melakukan DDL pada database source production.

Commissioning

Verifikasi source health, login/RBAC, monitoring Grafana, persistence setelah restart, alarm Response/Silence, report/archive, dan konektivitas lapangan. CI dan smoke test installer tidak menggantikan commissioning hardware nyata.
