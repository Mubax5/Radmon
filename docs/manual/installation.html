RadMon Installation Manual

Manual ini untuk PC3 central RadMon pada jaringan produksi. Database central tetap bernama ipradmon.

Konfigurasi .env

RADMON_DB_HOST=127.0.0.1
RADMON_DB_PORT=3306
RADMON_DB_NAME=ipradmon

RADMON_LAN_ENABLED=1
RADMON_LAN_SOURCES=gd50@192.168.1.50;gd52@192.168.1.52;gd38@192.168.1.38
RADMON_LAN_DB_PORT=3306
RADMON_LAN_DB_NAME=ipradmon
RADMON_LAN_POLL_INTERVAL=2

RADMON_BACKFILL_ENABLED=1
RADMON_BACKFILL_BATCH_SIZE=500
RADMON_BACKFILL_INTERVAL=2

Simpan username/password MariaDB hanya di file .env lokal. Jangan commit credential ke repository.

Menjalankan

Jalankan RUN_LAN.bat. Launcher menyalakan satu central collector/API owner, lalu membuka Admin. Docker tidak diperlukan untuk collector. Jika Windows PC3 tidak mendukung Docker, Grafana dapat dijalankan sebagai instalasi native Windows.

Alur data

vrecent dipoll setiap 2 detik untuk monitoring. Snapshot disimpan ke central recent, dan sample live juga dimasukkan idempotent ke measurement agar grafik live langsung memiliki titik data. History lama diambil worker backfill terpisah secara bertahap dan checkpointed.

Pemeriksaan

Test-NetConnection 192.168.1.50 -Port 3306
Test-NetConnection 192.168.1.52 -Port 3306
Test-NetConnection 192.168.1.38 -Port 3306

Log normal memperlihatkan baris [LIVE] untuk tiap source dan [BACKFILL] untuk import history. Source yang gagal tidak menghentikan source lain.

Grafana

Dashboard realtime membaca central vrecent. Trend dan sparkline membaca central measurement. Jika Grafana native digunakan, konfigurasi datasource tetap menunjuk ke MariaDB central PC3.
