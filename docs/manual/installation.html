Panduan instalasi

Instalasi Windows, konfigurasi awal, network boundary, upgrade, dan commissioning. Credential pada contoh selalu placeholder.

Pengguna Instalasi

Sebelum mulai

  • Gunakan akun Windows Administrator.
  • Siapkan account MariaDB least-privilege untuk central dan source LAN.
  • Siapkan Grafana native, reverse proxy HTTPS, trusted proxy network, allowed origin, firewall, dan ACL NTFS.
  • Siapkan backup yang sudah diuji restore sebelum upgrade atau migrasi.

Instalasi awal

  1. Jalankan RadMon-Setup.exe sebagai Administrator.
  2. Installer memasang application tree, membuat config\.env bila belum ada, mendaftarkan task RadMon Server, dan mendaftarkan RadMon Updater.
  3. Edit config\.env dengan nilai lokal yang disetujui. Contoh berikut tidak berisi credential nyata:
RADMON_CENTRAL_HOST=192.168.1.2
RADMON_DB_HOST=localhost
RADMON_DB_NAME=ipradmon
RADMON_DB_USER=<CENTRAL_DB_USER>
RADMON_DB_PASSWORD=<CENTRAL_DB_PASSWORD>

RADMON_LAN_ENABLED=1
RADMON_LAN_SOURCES=gd50@192.168.1.50;gd52@192.168.1.52;gd38@192.168.1.38
RADMON_LAN_DB_PORT=3306
RADMON_LAN_DB_USER=<SOURCE_DB_USER>
RADMON_LAN_DB_PASSWORD=<SOURCE_DB_PASSWORD>
RADMON_LAN_DB_NAME=ipradmon

RADMON_BOOTSTRAP_ADMIN_USER=<ADMIN_USERNAME>
RADMON_BOOTSTRAP_ADMIN_PASSWORD=<BOOTSTRAP_PASSWORD>
RADMON_BOOTSTRAP_ADMIN_PIN=<BOOTSTRAP_PIN>

RADMON_GRAFANA_PORT=3300
RADMON_GRAFANA_USER=admin
RADMON_GRAFANA_PASSWORD=GENERATE_ON_FIRST_START
RADMON_GRAFANA_DOCKER_FALLBACK=0

RADMON_WEB_COOKIE_SECURE=1
RADMON_TRUSTED_PROXY_NETS=<TRUSTED_PROXY_CIDR>
RADMON_WEB_ALLOWED_ORIGINS=https://monitoring.example
  1. Jika Grafana tidak ditemukan otomatis, isi RADMON_GRAFANA_BIN dengan path lokal ke grafana-server.exe.
  2. Pastikan reverse proxy HTTPS meneruskan origin dan forwarded protocol yang benar.
  3. Restart task RadMon Server atau reboot Windows.
  4. Login sebagai bootstrap Administrator, lalu hapus credential bootstrap dari .env setelah user terbentuk.

Hasil yang diharapkan: task berjalan sebagai SYSTEM saat boot, API tersedia melalui gateway 8090, Grafana tetap loopback pada 3300, dan client remote dapat login melalui HTTPS setelah routing/ACL diizinkan.

Pengecualian: admin/admin, password kosong, dan secret lemah ditolak. Konflik 3300 harus diperbaiki; RadMon tidak berpindah diam-diam ke 3301/3302.

config\.env, runtime, archives, dan reports dipertahankan saat upgrade. Manual HTML berada di app\docs\manual\; file Markdown source tidak seluruhnya ikut installer.

URL dan network boundary

https://monitoring.example/    Grafana monitoring, session RadMon wajib
https://monitoring.example/app Control Plane, session RadMon wajib
http://127.0.0.1:3300         Grafana admin/editor lokal

Firewall host membuka TCP 8090 untuk routed clients sesuai boundary BRIN-NET. Port 3300, 3306, dan 47652 bukan port client web. Jangan membuka database atau Grafana direct ke LAN sebagai jalan pintas.

Headless 24/7

Scheduled Task menjalankan:

app\RadMon.exe --server

Task memakai startup Windows sebagai SYSTEM, tersedia saat sistem kembali online, mengabaikan instance ganda, dan melakukan restart bounded sesuai konfigurasi. Shortcut RadMon memakai --start untuk recovery aman; shortcut RadMon Monitoring membuka landing monitoring.

Upgrade

  1. Pastikan backup terbaru dan restore drill owner masih valid.
  2. Pastikan tidak ada credential production yang belum dicatat dalam change record.
  3. Biarkan updater terverifikasi atau jalankan installer release yang telah disetujui sebagai Administrator.
  4. Updater memeriksa ancestry release, checksum SHA-256, marker, dan readiness health stabil. Application tree lama dipulihkan jika validasi gagal.
  5. Sesudah berhasil, verifikasi health, login/RBAC, source health, Grafana persistence, alarm, report, dan akses satu client BRIN-NET.

Jangan menghapus backup atau staging diagnostik sebelum validasi selesai.

Commissioning wajib

CI dan smoke test hanya memverifikasi artifact serta kontrak source. Simpan evidence untuk:

  • koneksi dan authentication central MariaDB serta source `.50`, `.52`, `.38`;
  • HTTPS, trusted proxy, allowed origin, firewall 8090, dan akses client BRIN-NET;
  • ACL NTFS pada `.env`, runtime, archive, report, dan security DB;
  • login role, Grafana datasource least privilege, transport/certificate, dan persistence;
  • rolling three-hour view, offline last-reading dengan timestamp asli, serta pembedaan datasource error dan query kosong;
  • source response `i_flag=0` menjadi `i_flag=1` dengan `ack` tidak berubah, retry/error handling, suppression, buzzer acceptance;
  • report 24 jam, full rows versus partial preview 250 baris, archive export, dan restore nyata.

Source code dan CI tidak merupakan sertifikasi keamanan, tidak membuktikan production deployment, dan tidak membuktikan buzzer fisik.
