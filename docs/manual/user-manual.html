RadMon User Manual

Station

Sidebar Station menampilkan tiga parent server LAN. Parent dapat di-collapse/expand dan menampilkan status koneksi source. Detector berada sebagai child berdasarkan source mapping yang disimpan collector.

Recent dan status

Nilai monitoring berasal dari vrecent. Status detector dihitung ulang dari timestamp terbaru, batas idle, dan threshold database sehingga detector yang kembali mengirim data tidak tetap OFFLINE.

Jika detector berstatus SUPPRESSED, measurement tetap berjalan. Dose rate aktual dan kondisi dasar NORMAL/ALERT/ALARM tetap terlihat bersama PIC, alasan, dan waktu berakhir suppression.

Station Properties

Administrator memilih detector lalu menekan Update. Pada mode LAN, perubahan Name, Location, Description, Low/High Threshold, Max Idle, Unit, dan Audio Path ditulis ke database source detector terlebih dahulu, kemudian disinkronkan ke central. Tag dan hardware identity tidak dapat diedit dari PC3.

PIN aksi sensitif yang valid memberikan akses sensitif selama 10 menit untuk user yang sama. Namun PIN yang secara eksplisit dimasukkan salah tetap ditolak.

Grafik

Tab Chart dan Grafana trend menggunakan measurement. Collector juga memasukkan sample live terbaru ke measurement, sehingga grafik saat ini tidak perlu menunggu backfill history selesai.

Alarm Policy

Alarm operator menggunakan policy restart-safe di central. Dalam satu burst, maksimal tiga ALARM dapat disurface. Window lima menit dihitung dari ALARM #1; HIGH pada atau sebelum lima menit tetap dalam burst yang sama. ALARM #3 langsung masuk RETRIGGER LOCKED.

ALERT tidak mereset episode. Trigger count dan lock hanya direset setelah dose benar-benar NORMAL, yaitu lebih rendah dari LOW/WARN threshold. Alarm historical/backfill tetap menjadi evidence tetapi tidak dikirim sebagai notifikasi baru.

ACK / Response

Untuk menangani alarm, pilih record lalu tekan ACK / Response, isi Action, PIC, Note/Reason, dan PIN. Source response menulis i_op, pic, note, serta mengubah i_flag dari 0 menjadi 1. Nilai ack dipertahankan dan tidak diubah.

Timed Suppression

Administrator dan Operator dapat memakai Suppress Alarm...; Viewer hanya dapat melihat. Durasi wajib 1 menit sampai 24 jam dan PIN, PIC, serta alasan wajib diisi. Satu detector hanya dapat mempunyai satu suppression aktif.

Opsi auto-resume aktif secara default. Jika dipilih, suppression selesai hanya ketika dose kembali NORMAL (< LOW/WARN). Sesi tanpa HIGH menghasilkan nol event SUPPRESSED. Satu atau banyak HIGH dalam sesi yang sama menghasilkan tepat satu event SUPPRESSED agar tidak spam.

Suppression tidak menghentikan measurement dan tidak menyembunyikan dose/status aktual. Jika suppression berakhir saat dose masih HIGH, alarm policy dapat menghasilkan alarm baru kecuali detector masih RETRIGGER LOCKED. Kegagalan silence ke source dicatat/audit dan diretry dengan backoff terbatas tanpa membuat event operator kedua.

Grafana

Operations menampilkan SUPPRESSED dari projection central radmon_runtime_status sambil mempertahankan dose rate dan kolom Underlying. Konversi WIB, refresh dashboard 2 detik, serta playlist 15 item dengan interval 10 detik tetap dipertahankan.

Refresh

Tekan F5 atau tombol Refresh untuk memuat ulang hierarchy source/station, status source, detail detector terpilih, pesan health, dan tab aktif. Auto-refresh live tetap berjalan tanpa membangun ulang tree pada setiap siklus.

Backfill

History lama diambil bertahap oleh worker BACKFILL terpisah. Checkpoint disimpan, sehingga restart melanjutkan dari posisi terakhir. LIVE monitoring dan alarm tetap berjalan independen.
