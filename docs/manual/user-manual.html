RadMon User Manual

Production RadMon berjalan otomatis 24/7 melalui Scheduled Task Windows yang menjalankan app\RadMon.exe --server. Browser user bukan lifecycle owner server.

Monitoring anonymous

Buka http://192.168.1.2:8090/ untuk Grafana monitoring fullscreen/kiosk. Halaman ini read-only, tidak mempunyai tombol Sign in RadMon, dan hanya tersedia untuk network BRIN/LAN yang diizinkan.

Control Plane dan role

Buka http://192.168.1.2:8090/app. Semua role wajib login, termasuk Viewer.

  • Viewer: Overview, Stations, History, Archives/Reports read-only.
  • Operator: Viewer + Alarm, Response/Silence, suppression.
  • Administrator: Operator + Users, station/system administration, Grafana admin.

Control Plane menggunakan Cloudflare Kumo UI. Backend tetap memeriksa session, role, dan PIN untuk aksi sensitif.

Grafana editable

Administrator pada PC server membuka http://localhost:3300. Login default Grafana adalah admin/admin bila belum diganti. Edit dan Save disimpan sebagai state Grafana authoritative dan langsung digunakan monitoring anonymous.

Restart RadMon, Grafana, Windows, atau installer upgrade tidak mengembalikan layout ke factory. Dashboard factory hanya di-seed bila UID belum ada.

Source health

gd50 -> 192.168.1.50
gd52 -> 192.168.1.52
gd38 -> 192.168.1.38

Kegagalan satu source tidak menghentikan source lain. RadMon tidak melakukan DDL pada source production.

Alarm Response / Silence

Operator/Administrator menangani policy event melalui menu Alarms. Aksi Response/Silence dan suppression memerlukan role yang sesuai serta PIN. Source write-through mengisi i_op, pic, note, dan i_flag=1; ack tidak diubah.

Timed suppression

Suppression berlangsung 1 menit sampai 24 jam dengan PIN, PIC, dan reason. Measurement tetap berjalan dan dose aktual tetap terlihat. Satu sesi maksimal menghasilkan satu event SUPPRESSED.

Reports dan archive

Workflow report: Preview -> Print / Export PDF / Export CSV. Reports dapat membaca data aktif dan quarterly archive yang sudah terverifikasi tanpa restore SQL.

Operasi 24/7

Scheduled Task RadMon Server start saat Windows boot sebagai SYSTEM dan restart otomatis bila proses berhenti. Menutup browser tidak menghentikan collector/API.

Upgrade

Jalankan installer baru sebagai Administrator. Pertahankan config\.env, runtime\, archives\, dan reports\. Setelah upgrade verifikasi monitoring, login/RBAC, Grafana Save persistence, source health, alarm, dan report.

Jika ada masalah

Periksa Scheduled Task RadMon Server, runtime\logs, port 8090/3300, Grafana native, serta central/source MariaDB. Jangan menghapus security DB/checkpoint/archive/report sebagai langkah troubleshooting.
