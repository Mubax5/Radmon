RadMon User Manual

Production central dimulai dengan app\RadMon.exe. Satu proses RadMon memiliki collector LAN, secure API, desktop Admin, alarm policy, archive lifecycle, dan Grafana bootstrap.

Login dan role

  • Administrator: monitoring, Response/Silence, suppression, user management, edit station, archive admin.
  • Operator: monitoring/report, Response/Silence, suppression.
  • Viewer: read-only.

Monitoring

Tab utama adalah Recent, Tabular, Chart, Reports, Alarm, dan Logs. Monitoring realtime menggunakan snapshot vrecent dengan refresh default 2 detik.

Tombol Monitoring membuka Grafana Playlist Realtime, Trends, dan Operations. Dashboard refresh 2 detik; Playlist berganti setiap 10 detik.

Source health

gd50 -> 192.168.1.50
gd52 -> 192.168.1.52
gd38 -> 192.168.1.38

Status source dapat berupa CONNECTED, DEGRADED, OFFLINE, atau RECOVERED. Kegagalan satu source tidak menghentikan source lain.

Alarm Response / Silence

  1. Pilih alarm aktif.
  2. Klik Response / Silence.
  3. Isi Action, PIC, Note/Reason, dan PIN bila diminta.
  4. Submit dan verifikasi event menjadi responded.

Write-through source mengisi i_op, pic, note, dan i_flag=1. Kolom ack tidak diubah.

Timed suppression

Administrator/Operator dapat men-suppress alarm detector selama 1 menit sampai 24 jam dengan PIN, PIC, dan reason. Measurement tetap berjalan; dose aktual dan underlying NORMAL/ALERT/ALARM tetap terlihat. Satu sesi menghasilkan paling banyak satu event SUPPRESSED.

Reports

Workflow report: Preview -> Print / Export PDF / Export CSV. Reports dapat membaca data aktif dan quarterly archive yang sudah terverifikasi.

Shutdown dan upgrade

Tutup desktop Admin untuk shutdown normal; central service milik RadMon ikut berhenti. Saat upgrade, pertahankan config\.env, runtime\, archives\, dan reports\.

Jika ada masalah

Periksa Logs, source health, central MariaDB, dan Docker Desktop/Grafana. Jangan menghapus security DB, checkpoint, archive, report, atau konfigurasi production sebagai langkah troubleshooting.
